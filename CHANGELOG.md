# Changelog / История изменений

## 2.3.0

- Russian and English UI, persistent language selection on restart, translated errors and worker messages.
- Bilingual documentation, Windows CI, GitHub templates and packaged translation catalogs.
- Personal Canva links replaced with environment variables; synthetic Office fixture metadata anonymized.

- Русский и английский интерфейсы, сохранение языка с применением после перезапуска, перевод ошибок и сообщений помощников.
- Документация на двух языках, Windows CI, шаблоны GitHub и включение словарей в сборки.
- Личные ссылки Canva заменены переменными окружения; метаданные искусственных тестов Office обезличены.

## 2.2.0

Canva viewing links with animations and video, loop controls, WebView2 preflight and Windows Setup.

Canva по ссылке с анимациями и видео, повтор роликов, проверка WebView2 и установщик Windows.

## 2.1.0

Scene branding, mixed media queue, standalone images/video, scaling, player and refreshed UI.

Название «Сцена», смешанная очередь, отдельные изображения и видео, масштабирование, плеер и обновлённый интерфейс.
