**«Сцена»** — приложение для Windows: PDF, PowerPoint, Canva, изображения и видео в одном окне докладчика. Заметки и управление остаются перед вами, аудитория видит показ.

В **версии 2.3.0** доступны **русский и английский** интерфейсы. Выберите **Язык / Language → Русский / English** и перезапустите приложение. По умолчанию используется русский. Выбор языка не прерывает показ и не переводит ваши заметки и имена файлов. Установщик Windows — `Scene-Setup-2.3.0-x64.exe`.

## Возможности

- Общая очередь презентаций, изображений, видео и ссылок Canva; добавление папок, перетаскивание файлов и изменение порядка.
- Текущий и следующий слайды, миниатюры, переход по номеру, приватные заметки, таймер и часы.
- Плеер: пуск/пауза, стоп, перемотка, громкость и повтор — в зависимости от движка.
- Масштаб изображений и видео: вписать, заполнить, растянуть, исходный размер или 1–1000%; увеличенный предпросмотр можно перемещать мышью.
- Чёрный/белый экран, заставка, удержание кадра и защитное покрытие аудитории при переключении движков.
- Проекты мероприятий (`.pdfpresenter`) с относительными путями, очередью и настройками медиа.
- Отдельное окно аудитории; при одном мониторе — обычный оконный предпросмотр.

## Требования и ограничения

Windows 10 версии 1809 или новее либо Windows 11, **x64**. Готовые сборки включают Python, Qt, MuPDF и библиотеки отдельного плеера. Наборы кодеков отдельно не нужны; расширение контейнера не гарантирует поддержку любого кодека внутри.

| Материалы | Нужно дополнительно | Ограничения |
| --- | --- | --- |
| PDF | Ничего | Статические слайды; поддерживается ввод пароля |
| Изображения | Ничего | Форматы Qt, включая PNG, JPEG, BMP, WebP, TIFF, GIF и SVG; первый кадр анимированных и многостраничных файлов |
| Отдельные видео | Ничего | MP4, MKV, AVI, MOV, WebM и другие; воспроизведение зависит от кодека |
| Нативные PPT/PPTX | Microsoft PowerPoint | Нативные анимации и медиа; громкость встроенного видео не регулируется |
| Совместимость PPT/PPTX | LibreOffice либо PDF с тем же именем рядом с презентацией | В PDF нет анимаций, звука и видео; нативный Impress экспериментальный |
| Canva | Интернет, публичная ссылка, WebView2 Runtime, .NET Framework 4.6.2+ | Без входа в аккаунт, DRM и сторонних iframe-видео; нет следующего предпросмотра и импорта заметок Canva |

Локальные файлы работают офлайн, Canva требует интернет. Установить WebView2 можно через **Справка → WebView2 для Canva**; в Setup он не включён. Canva открывается в отдельном встроенном браузере. Программа не меняет дизайн и права доступа. Обновления просмотрщика Canva могут влиять на совместимость.

Повтор PowerPoint реализован, но ещё требует проверки фактического воспроизведения. Повтор отдельных видео и Canva проверялся до локализации. Звук, мониторы и нативный Office нужно также проверять на целевом компьютере.

## Начать показ

1. Запустите `PDFPresenter.exe` из полного каталога portable-сборки либо установите `Scene-Setup-<версия>-x64.exe`. Техническое имя EXE сохранено для совместимости.
2. Нажмите **Добавить материалы**, перетащите файлы или используйте **Ссылка Canva**. Ссылки редактора Canva открываются для просмотра.
3. Выберите экран аудитории. Для двух мониторов включите **Расширить** в Windows (Win+P).
4. Нажмите **F5** для начала либо **Shift+F5** с выбранного слайда.
5. Управляйте видео под предпросмотром. **Повтор** зацикливает ролик; у отдельного видео это приостанавливает автоматический переход по очереди. Громкость меняется у ролика, общая громкость Windows сохраняется.
6. Нажмите **Esc** или **Завершить**. Сохраните мероприятие через **Ctrl+Shift+S**.

Масштаб, положение, громкость и повтор отдельного видео сохраняются в проекте. Повтор встроенного видео Canva/PowerPoint действует в текущем сеансе. Заметки автоматически сохраняются и остаются только у докладчика.

| Клавиша | Действие |
| --- | --- |
| → / ↓ / Space / PageDown | Следующий слайд или шаг нативной анимации |
| ← / ↑ / PageUp | Предыдущий слайд |
| Home / End | Первый / последний слайд |
| Цифры + Enter | Перейти к номеру слайда |
| B / W | Чёрный / белый экран; повторное нажатие возвращает слайд |
| Ctrl+O | Открыть материал |
| Ctrl+S / Ctrl+N | Сохранить заметки / перейти в редактор |
| Ctrl+PageDown / Ctrl+PageUp | Следующий / предыдущий файл |
| Ctrl+Enter / Ctrl+L | Открыть выбранный файл / перейти к очереди |

В текстовых полях навигация отключена. F5/Shift+F5 обнуляют таймер; Esc сначала отменяет ввод номера, затем завершает показ.

## Разработка

Нужен Python **3.12 x64** для Windows. Команды PowerShell из корня проекта:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation -e ".[dev]"
.venv\Scripts\python.exe main.py
```

Lock-файл фиксирует проверенное окружение Windows; диапазоны версий указаны в `pyproject.toml`. Переменная `SCENE_LANGUAGE=en` либо `ru` переопределяет сохранённый язык для процесса и его помощников.

```powershell
.venv\Scripts\python.exe -m ruff check src tests scripts
.venv\Scripts\python.exe -m ruff format --check src tests scripts
.venv\Scripts\python.exe -m pytest -q
```

Обычные тесты работают без показа окон, Office, аккаунтов и интернета. Нативные проверки включаются отдельно — см. [CONTRIBUTING.md](CONTRIBUTING.md). GitHub Actions запускает Windows-проверки, тесты RU/EN и сборку wheel; релизы не публикуются автоматически.

`build.bat` собирает приложение через PyInstaller, `build_setup.bat` — установщик Inno Setup. Сохраняйте весь `dist/PDFPresenter`, включая `_internal`. В новые сборки включаются оба README.

```powershell
.\build_setup.bat -RebuildApp
.\build_setup.bat -InnoCompiler "C:\Program Files\Inno Setup 7\ISCC.exe"
pwsh -File scripts/test_setup.ps1 -Isolated
```

Setup может скачать официальный подписанный компилятор Inno Setup 7.1.1 в `artifacts/tooling`; для первой подготовки нужен интернет. Установка приложения выполняется для текущего пользователя, цифровой подписи пока нет. Изолированный тест использует отдельный AppId и защищает существующую установку.

## Данные и публикация

Настройки, заметки и логи остаются в `%APPDATA%\PDFPresenter`. Форматы старых проектов сохранены. Проекты содержат ссылки на материалы, а не сами файлы; при переносе мероприятия сохраняйте доступ к ним.

Сборки, журналы, ключи, локальные рабочие записи и пользовательские проекты исключены из Git. Тестовые файлы Office искусственные, метаданные автора обезличены. Ссылки для живых тестов Canva задаются переменными окружения.
